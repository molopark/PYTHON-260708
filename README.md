# 👥 SQLite 회원 등록 및 관리 프로그램

SQLite 데이터베이스를 기반으로 회원 정보를 저장하고 관리하는 대화형 CLI(Command Line Interface) 프로그램입니다.

## 주요 기능
* **회원 등록**: 회원 ID(중복 검증), 이름, 이메일, 전화번호를 입력받아 등록합니다.
* **전체 회원 조회**: 정렬된 표 형태로 등록된 모든 회원들의 목록을 보여줍니다.
* **회원 검색**: ID 또는 이름의 일부만으로 회원을 편리하게 검색합니다.
* **회원 정보 삭제**: 삭제할 회원의 ID를 입력하고 한번 더 확인한 뒤 안전하게 삭제합니다.

## 기술 스택
* **Language**: Python 3.x
* **Database**: SQLite3 (파이썬 내장 라이브러리 사용)

## 실행 방법
1. 이 저장소를 클론하거나 다운로드합니다.
2. 터미널(또는 CMD)에서 아래 명령어를 통해 실행합니다:
   ```bash
   python test.py
   ```
